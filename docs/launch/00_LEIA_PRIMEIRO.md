## Como usar
1. Extraia este ZIP e coloque estes arquivos em docs/launch/ no repositório.
2. Abra o projeto no Claude Code ou ambiente com leitura, edição e terminal.
3. Envie o texto integral de 01_PROMPT_MESTRE_CLAUDE.md.
4. O Claude deve auditar e implementar o que estiver disponível; manter pendências externas explícitas.
5. Traga para este chat AUDITORIA.md, PENDENCIAS_EXTERNAS.md e RESULTADOS_QA.md. Eles permitem orientar a configuração com fatos.
Se estiver usando Claude apenas em chat, anexe o projeto sem segredos ou conecte o repositório. Sem acesso ao código ele só poderá propor mudanças.
